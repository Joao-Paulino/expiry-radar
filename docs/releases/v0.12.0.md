## M9: Software licensing — FlexLM / Licenciamento de software — FlexLM

- **FlexLM/FlexNet (Flexera) license files** (`.lic`/`.dat`): reads every `FEATURE`/`INCREMENT` line's expiration date. Local files only — querying a running license daemon (`lmgrd`/`lmstat`) over the network is not supported.
- Non-expiring licenses are recognized and skipped: `permanent`, or a zero year (`0`, `00`, `000`, `0000`).
- Legacy 2-digit years are supported (always `19xx`, per the FLEXlm FAQ); years 2000+ must use all 4 digits.
- Multi-line `SIGN=` blobs (backslash line continuation) are handled correctly, without mistaking a comment's trailing backslash for a continuation.
- A duplicate feature name in one file (e.g. an old grant plus a renewal) gets a distinct record, so a renewal is never hidden behind a stale/expired entry of the same name.
- UTF-8 BOM-prefixed files (common from Windows editors) are handled.
- New config option: `licensing.flexlm_license_files` in the agent config. Example: `examples/agent/scada-licensing.json`.
- Other licensing systems (CodeMeter, Sentinel RMS/HASP, SaaS subscriptions) are not covered yet — open an issue naming the vendor and, ideally, a sample license file or API response.

---

- **Ficheiros de licença FlexLM/FlexNet (Flexera)** (`.lic`/`.dat`): lê a data de expiração de cada linha `FEATURE`/`INCREMENT`. Só ficheiros locais — consultar um daemon de licenças (`lmgrd`/`lmstat`) pela rede não é suportado.
- Licenças sem expiração são reconhecidas e ignoradas: `permanent`, ou um ano a zeros (`0`, `00`, `000`, `0000`).
- Suporte para anos legados de 2 dígitos (sempre `19xx`, conforme a FAQ do FLEXlm); anos a partir de 2000 têm de usar 4 dígitos.
- Blocos `SIGN=` em várias linhas (continuação com `\`) são tratados corretamente, sem confundir um `\` no fim de um comentário com uma continuação.
- Um nome de funcionalidade repetido no mesmo ficheiro (ex. licença antiga + renovação) gera um registo distinto, para a renovação nunca ficar escondida atrás de uma entrada antiga/expirada com o mesmo nome.
- Ficheiros com BOM UTF-8 (comuns em editores Windows) são tratados corretamente.
- Nova opção de configuração: `licensing.flexlm_license_files` no agente. Exemplo: `examples/agent/scada-licensing.json`.
- Outros sistemas de licenciamento (CodeMeter, Sentinel RMS/HASP, subscrições SaaS) ainda não são suportados — abre uma issue a indicar o fabricante e, idealmente, um ficheiro de licença ou resposta de API de exemplo.
