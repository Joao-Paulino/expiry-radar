## M8: Cloud IoT / IoT na cloud

- **AWS IoT Core**: device certificates (`ListCertificates` + `DescribeCertificate`, revoked ones skipped) and registered CA certificates (`ListCACertificates` + `DescribeCACertificate`, inactive ones skipped). Both paginators stop on a repeated page marker instead of looping.
- **Azure IoT Hub and Device Provisioning Service (DPS)**: X.509 CA certificates (`properties.expiry`, parsed from the real RFC 7231/RFC1123 format these resources use).
- New config option: `iot_core` in AWS `services`, `iot_certificates` in `azure`. Example: `examples/agent/iiot-iot.json`.

---

- **AWS IoT Core**: certificados de dispositivo e CAs registadas, com a mesma lógica de paginação e de ignorar os que estão revogados/inativos.
- **Azure IoT Hub e Device Provisioning Service (DPS)**: certificados de CA X.509, com o formato de data real (RFC 7231/RFC1123).
- Nova opção de configuração: `iot_core` (AWS) e `iot_certificates` (Azure).
