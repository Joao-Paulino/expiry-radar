## M10 (first step): end of support, firmware, contracts / Fim de suporte, firmware, contratos

- **Inventory checker**: dates no API exposes, kept in a CSV or JSON file (device end of support, firmware security support, support contracts, warranties, domains), alerted like any certificate. Read only: it never contacts the devices. Bad rows are reported with their line number; Excel CSV accepted. Example: `examples/ot-assets.csv`.
- **Example configs** for every option and per scenario (Azure, AWS, GCP, Vault, VMware, Windows/IIS, OT/ICS, IIoT/IoT), all validated by tests: `examples/`.
- **SSO** documented for Okta and any OIDC identity provider.
- **Collector certificate guide**: which option to choose, internal CA (AD CS), Let's Encrypt deploy hook, ZeroSSL.
- **Releases are immutable** from this version: built, scanned and published by the pipeline with every asset (binaries, SBOM, VEX, LICENSE, SHA256SUMS, signed provenance).
- README: 3-minute install, demo, comparison with other tools; roadmap M10 and M11.

---

- **Checker de inventário**: datas que nenhuma API expõe, num ficheiro CSV ou JSON (fim de suporte de equipamentos, firmware, contratos de suporte, garantias, domínios), com alertas como qualquer certificado. Só leitura: nunca contacta os equipamentos.
- **Exemplos de configuração** completos e por cenário, validados por testes.
- **SSO** documentado para Okta e qualquer IdP OIDC; guia de certificados do collector.
- **Releases imutáveis** a partir desta versão.
